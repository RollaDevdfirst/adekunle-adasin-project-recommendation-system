# Components Directory

Reusable UI components organized by function.

## Subdirectories:

### common/
Shared components used across multiple pages:
- Header
- Footer
- Navigation
- Sidebar
- SearchBar
- Pagination
- Modals
- Alerts

### admin/
Admin-specific components:
- FileUpload.jsx
- ResourceForm.jsx
- AdminTable.jsx
- AdminStats.jsx

### recommendation/
Recommendation section components:
- ResourceCard.jsx
- ResourceGrid.jsx
- RecommendationList.jsx
- FilterPanel.jsx

## Guidelines:
- Each component should have its own folder with JSX and CSS file
- Keep components small and focused on a single responsibility
- Use props for data and callbacks
