# Hooks Directory

Custom React hooks for reusable logic.

## Files:
- `useFetch.js` - Generic data fetching hook with loading/error states
- `useSearch.js` - Search and filter logic
- `useFilter.js` - Advanced filtering
- `useAuth.js` - Authentication context
- `usePagination.js` - Pagination logic

## Purpose:
Encapsulate stateful logic to reuse across multiple components.
Keep components focused on rendering, not logic.
